Guia de Implementação

Este guia orienta a equipe técnica do portal parceiro a injetar o player de vídeo monetizado dentro de matérias e páginas web, garantindo a leitura dinâmica da URL atual para entrega precisa de anúncios instream.

Passo 1: Definir o posicionamento (HTML)

O código gerado na etapa "Container HTML" é apenas uma estrutura vazia (uma <div>). Ela serve como uma "âncora". O desenvolvedor ou o redator no CMS deve colar esse pequeno trecho de HTML exatamente onde o vídeo deve quebrar o texto da matéria.

  • Não possui estilos conflitantes.
  • Já possui lógica responsiva de 16:9 (o vídeo se adapta ao tamanho da tela de celulares e desktops).

Passo 2: Injetar o Comportamento (Script)

O script gerado é auto-contido. Ele verifica se as bibliotecas de reprodução de vídeo já existem no site. Se não existirem, ele as baixa de forma assíncrona para não deixar o site parceiro lento.

Onde colocar o Script?

  • Via Google Tag Manager (Recomendado): Crie uma tag do tipo "HTML Personalizado", cole o script gerado, e defina o acionador para as páginas de matérias (Page View).
  • Via CMS: Cole o script no final do corpo da página (próximo ao fechamento da tag </body>).

Passo 3: A Mágica da Tag VAST

O script gerado automaticamente detecta a URL da página do parceiro no momento em que o usuário a acessa e injeta essa informação na Macro {{PAGE_URL}} da requisição do anúncio. Isso garante que as métricas de Viewability e origem do tráfego sejam precisas e transparentes.

Nota Técnica: O player suporta tanto vídeos hospedados (MP4) quanto a camada de sobreposição inteligente para iframes do YouTube, mantendo a conformidade técnica sem quebrar o ecossistema do site origem.
